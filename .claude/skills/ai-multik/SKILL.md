# ИИ-мультики «Что если ты...»

Скилл собран по разбору эталона «Палата с бывшей» (@chto_esli_ty, 55 с). Делает ролик целиком здесь: сценарий → картинки (Virale) → голос (RHVoice / ElevenLabs) → монтаж и звук (render.py) → mp4.

Путь скилла дальше — `$S` = `.claude/skills/ai-multik`. Эпизоды живут в `multiki/<id>/` в корне репозитория.

## Справочники — читать перед работой

- `references/story-formula.md` — **как писать**: покадровый разбор эталона, 14 правил текста, структура по секундам, банк идей. Читать всегда перед сценарием.
- `references/visual-style.md` — палитра, мастер-промпт картинок, правила композиции, каталог стикеров и монтажных приёмов.
- `references/sound.md` — голос (что было в оригинале, какой голос выбрать), библиотека из 43 эффектов, дозировка.
- `references/episode-format.md` — все поля episode.json и команды.
- `templates/palata-s-byvshey/episode.json` — эталон, разложенный на 24 шота. Копируй его как основу.

## Порядок работы

### 0. Среда (один раз за сессию)
```bash
bash $S/scripts/setup.sh
```
Ставит ffmpeg и RHVoice из apt, генерирует звуки в `assets/sfx`. Шрифты уже в `assets/fonts`.

### 1. Сценарий
1. Возьми идею пользователя (или из банка идей) и заполни карточку: герой, антипод, возраст/место, 5 закладок (год, предмет, животное, место, имя друга), шкала HUD, авторитет, тёплая нота, финальный обмен репликами, название-эпитафия, CTA.
2. Напиши текст по правилам `story-formula.md`: 150–175 слов, предложения 3–9 слов, второе лицо, мат только `{з****ой}`.
3. **Покажи пользователю сценарий и карточку и дождись правок** до генерации картинок — картинки стоят денег.

### 2. Раскадровка → episode.json
Скопируй эталон в `multiki/<id>/episode.json` и замени шоты. 18–26 шотов, 1–3 реплики на шот. Каждому шоту: `prompt`, `motion` (чередуй крупности и движения), 0–2 стикера на ключевых словах (`at_word`), `hud` на скачках времени, `fx: ["sepia"]` + `transition: "whip"` на флешбеки.

Сразу собери черновик без картинок — проверить тайминг (заглушки рисуются сами):
```bash
python3 $S/scripts/render.py multiki/<id>/episode.json --preview
```
Длина должна быть 45–58 с. Длиннее — режь текст, а не ускоряй голос выше 1.25.

### 3. Картинки (Virale, тратит баланс)
1. `virale_ai_balance` и `virale_generation_estimate` — сообщи пользователю цену (`gemini_2_lite` 1K ≈ 4 цента за кадр, 20 кадров ≈ $0.8).
2. Сначала референс-лист персонажей (1:1, «character sheet, front view, full body, same style»), покажи пользователю.
3. Кадры: `virale_image_generate` с мастер-промптом из `visual-style.md` + описанием персонажей из `characters` дословно + URL референса в `images`. Аспект 9:16. Для серии похожих кадров удобнее `virale_sequence_generate` (до 20 за раз, держит стиль; есть стоимость подготовки ~50 центов).
4. Опрашивай `virale_generation_status`, затем скачай:
   ```bash
   python3 $S/scripts/fetch_images.py multiki/<id> 01=<url> 02=<url> cat_angel_cut=<url>
   ```
   Суффикс `_cut` вырезает однотонный фон (для стикеров `image`: кот с нимбом и т.п. — проси «on plain white background»).
5. Посмотри каждую картинку (Read). Лишний текст/уродства — перегенерируй только этот кадр.

Если баланса нет — можно оставить заглушки и попросить пользователя положить свои картинки в `multiki/<id>/img/` с теми же именами.

### 4. Голос
По умолчанию RHVoice `artemiy`, `tempo` 1.15–1.2. Сэмплы голосов — `assets/voice-samples/*.mp3`; отправь их пользователю (SendUserFile), если голос ещё не выбран. Проверить ударения и длительности:
```bash
python3 $S/scripts/voice.py multiki/<id>/episode.json
```
Неверное ударение — `+` перед ударной гласной в реплике. ElevenLabs: `"engine": "elevenlabs", "voice": "<voice_id>"` и `ELEVENLABS_API_KEY` (в облачной среде домен закрыт — см. `sound.md`).

### 5. Рендер и проверка
```bash
python3 $S/scripts/render.py multiki/<id>/episode.json --still 0.5 10 30 50   # ключевые кадры
python3 $S/scripts/render.py multiki/<id>/episode.json                       # финал, ~3–4 мин
```
Проверь стиллы (Read): стикеры не закрывают лица, субтитры читаются, HUD меняется. Потом контактный лист финала:
```bash
ffmpeg -v error -y -i multiki/<id>/build/<id>.mp4 -vf "fps=1,scale=180:-1,tile=10x6" -frames:v 1 multiki/<id>/build/sheet.jpg
```
Отправь пользователю mp4 и `cover.png` через SendUserFile.

## Чек-лист перед отдачей

- [ ] Хук и титул понятны без звука за 1.5 с; обложка = первый кадр с титулом.
- [ ] 45–58 с, ~30 смен плана, ни один шот не стоит дольше 4 с без движения или стикера.
- [ ] Закладки из первой трети вернулись в середине (список/стена) и одна — в финальном панчлайне.
- [ ] HUD-шкала меняется 3–5 раз и в финале доходит до предела (0 / максимум).
- [ ] Есть тёплая нота перед финалом; последнее слово за героем.
- [ ] Мат только под звёздочками и с писком; не больше 3 раз.
- [ ] Эффекты не чаще раза в 2–3 с; голос всегда громче эффектов.
- [ ] Метка «AI-generated» на месте (правило TikTok/VK для ИИ-контента).
- [ ] В кадре нет чужих логотипов и водяных знаков; ник в CTA/шапке — свой, а не @chto_esli_ty.

## Чего не делать
- Не копировать чужие эпизоды дословно для публикации: эталон — учебный разбор, сюжеты пиши свои.
- Не генерировать картинки до согласования сценария.
- Не ставить фоновую музыку «для атмосферы» — у оригинала её нет, голос и титры держат внимание сами. Музыка — только если пользователь просит.
