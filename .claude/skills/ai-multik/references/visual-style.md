# Визуальный стиль и монтаж

## Картинка

Плоская 2D-векторная анимация в духе explainer-роликов (Vyond / Animaker): простые фигуры, тонкий тёмный контур, без градиентов, мягкие плоские тени, лёгкая бумажная зернистость.

**Палитра оригинала**

| Роль | Цвет |
|---|---|
| Стены | тёплый беж `#E9DCC6`, низ стены мятный `#BFE0D2` |
| «Его» сторона | бледно-голубой `#CFE0F0`, пижама в бело-голубую полоску |
| «Её» сторона | пыльно-розовый `#F2D3DC`, халат розовый в ромашки |
| Флешбек | сепия, тёплый жёлто-коричневый, виньетка |
| Акценты интерфейса | жёлтый `#FFD60A`, красный `#E22626`, оранжевый `#F58C1E`, тёмная плашка `#1C1C20` |

**Персонажи:** большие круглые головы, глаза — белые кружки с чёрной точкой, нос-кнопка, руки-палочки с круглыми кистями. Каждому персонажу — один костюм-маркер, узнаваемый в любом плане (полосатая пижама / халат в ромашки / белый халат врача). Возраст передают седина, морщинки, очки.

## Мастер-промпт для генерации кадров

Вставляется в начало каждого промпта картинки (провайдер Virale `gemini_2_lite` 1K — 4 цента за кадр; `gemini_pro` 2K — для обложки):

```
Flat 2D vector cartoon in the style of explainer animation (Vyond / Animaker style), vertical 9:16 frame.
Muted pastel palette: warm beige walls, mint-green lower wall panel, dusty pink and pale blue accents,
soft flat shadows, no gradients, thin dark outlines, clean simple shapes, slight paper grain.
Characters have big round heads, small dot eyes with white sclera, simple stick-like limbs with round hands.
[СЦЕНА]. [ПЕРСОНАЖИ из episode.json → characters, дословно].
Camera: [план]. Keep the upper third of the frame calm (space for stickers) and the bottom 20% simple (space for subtitles).
No text, no letters, no captions, no watermark.
```

Правила композиции:
- **Верхняя треть кадра пустая** — туда ложатся стикеры, HUD и шапка.
- **Нижние 20% простые** (пол) — там субтитры.
- Персонаж в нижне-средней части, крупность меняется каждые 2–3 кадра: общий → средний → крупный лица → общий.
- Сплит-экран для пар «у тебя / а у неё»: левая половина голубая с ним, правая розовая с ней.
- Флешбеки: те же герои молодыми, в сепии (рендер сам красит `fx: ["sepia"]`).
- **Согласованность героев:** сгенерируй сначала референс-лист персонажей (`virale_image_generate`, 1:1, «character sheet, front view, same style»), затем передавай его URL в `images` каждого кадра. Либо делай пачку кадров одним `virale_sequence_generate` — он держит общий стиль.
- Надписи в кадре (КОТ, ДИВАН, МАМА на стене) модель пишет плохо — проси рисунки без подписей, а подписи давай стикерами.

## Монтаж (что делает render.py)

| Элемент | Как в оригинале | Параметр |
|---|---|---|
| Формат | 9:16, 1080×1920, 30 к/с, 50–58 с | — |
| Склейки | жёсткая склейка на каждую реплику, средний шот 1.5–2.5 с (~30 смен плана за ролик) | шот = 1–3 реплики |
| Камера | медленный наезд/отъезд (Ken Burns), панорамы, резкий «punch»-наезд на реакцию, тряска на шок | `motion` |
| Переходы | в основном cut; whip-pan со свистом на флешбек и смену дня; белая вспышка на шок | `transition` |
| Частицы | плавающие пылинки по всему ролику | всегда (выкл. `no_particles`) |
| Шапка | слева сверху: красная мигающая точка «● ЧТО ЕСЛИ ТЫ... · НАЗВАНИЕ», Montserrat ExtraBold, белый | `series`, `episode` |
| HUD | справа сверху тёмная плашка, моноширинный шрифт: «ДЕНЬ 1 / БЕЛЫХ СТЕН: 4», значения жёлтые, при изменении мигают красным + щелчок | `hud`, `shot.hud` |
| Титул | первые ~1.3 с: тёмная скруглённая плашка с розовой обводкой, «ты в старости / С *БЫВШЕЙ* / В ДУРКЕ / стены были белые» | `title_card` |
| Субтитры | Montserrat Black, ВЕРХНИЙ РЕГИСТР, белые с чёрной обводкой и тенью, по 2–3 слова, текущее слово жёлтое, на 83% высоты | `caption_words`, `caption_y` |
| Цензура | в титрах звёздочки с первой и последней буквой, в звуке двухтональный писк | `{о****л}` |
| CTA | жёлтая плашка с чёрной рамкой по центру + тёмная таблетка с названием эпизода вместо субтитров | `cta`, `tag` |
| Метка | «AI-generated» слева внизу (требование TikTok к ИИ-контенту) | `ai_label` |

## Стикеры (графика поверх кадра)

Появляются «pop» с перелётом масштаба (easeOutBack) точно на слове, к которому относятся (`at_word`). 1–2 стикера на шот, не больше.

| Тип | Пример из оригинала | Когда использовать |
|---|---|---|
| `big` | жёлтые «84», «50 ЛЕТ» с чёрной обводкой | цифра-факт |
| `stamp` | красная печать «БЫВШАЯ», наклон −7° | ярлык на персонажа |
| `label` style `orange` | «ШИЗА \| ДЕМЕНЦИЯ» | сравнение двух диагнозов/ролей |
| `label` style `white_tag` | «ИМЯ: ?» | бирка, вопрос |
| `label` style `sepia` | «ФЛЕШБЕК», «В ОДНОМ ТАПКЕ» | всё внутри воспоминания |
| `label` style `red_outline` | «КАК ПЕРЕД РАЗВОДОМ» | ироничный комментарий |
| `label` style `green` + `kicker` | «НЕПЛОХО. / АРТ-ТЕРАПИЯ» | вердикт авторитета |
| `label` style `yellow` | «1 ЧАС БЕЗ ССОРЫ» | достижение, рекорд |
| `list` | свиток «КОСЯКИ: кот, диван, 1998, топор, сугроб...» | закладки, которые выстрелят позже |
| `polaroid` | фото 1998 с котом; «СЕРЁГА — так и не женился» | прошлое, третьи лица |
| `bubble` (+`strike`) | «БЕ!», зачёркнутое «ЗАЧЕМ?» | реплика, несказанное |
| `thought` | облачко с тремя копиями героя (шиза) | мысли, галлюцинации |
| `calendar` | отрывной календарь «ДЕНЬ 1 → 3» | скачок времени |
| `check` | зелёная галочка | одобрение |
| `clipboard` | планшет «НАБЛЮДЕНИЕ» с рукописной записью | протокол, заметки врача |
| `image` | кот с нимбом и крыльями | любая PNG с прозрачностью |

Шрифты (лежат в `assets/fonts`, лицензия SIL OFL): Montserrat Black/ExtraBold/Bold — титры, плашки, шапка; JetBrains Mono ExtraBold — HUD; Caveat Bold — рукописное (подписи на полароиде, список, планшет).
