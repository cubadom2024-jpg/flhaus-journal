# Журнал FL Haus → Яндекс Дзен

Статический блог с RSS-лентой в формате Дзена. Агент Claude по будням пишет статью, кладёт её в `articles/`, собирает сайт в `docs/` и публикует на GitHub Pages. Дзен забирает новые статьи из `rss.xml` в канал.

- `AGENT.md` — инструкция агента на каждый запуск
- `topics.md` — журнал публикаций и банк тем
- `config.yaml` — домен, режим Дзена (`draft` / `publish`), время выхода
- `build.py` — сборка сайта и ленты, `--check` — только проверка
- `tools/infographic.py` — инфографика и обложки, `tools/photo.py` — подготовка фото
- `photos/` — библиотека фото домов FL Haus для обложек
- `verify/` — файлы подтверждения прав на сайт (Дзен, Вебмастер), копируются в корень сайта

Переключить Дзен с черновиков на автопубликацию: `dzen_mode: "publish"` в `config.yaml`.
